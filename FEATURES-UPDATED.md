# QODEKRAFT Updated Workflow

- Student signup creates a `pending` account.
- Student login never auto-approves an account.
- Student login requires manual admin approval AND at least one active domain assignment.
- Admin sees the student's requested domain from signup and can assign an active domain after approval.
- Students can submit assignment files and view review status/feedback.
- Students can submit project descriptions, GitHub/live-demo links, and project files.
- Admin can review assignment submissions with status, marks, feedback, and correction requests.
- Admin can review project submissions with status, marks, and feedback.
- Admin can open a student overview showing domains, assignment submissions, project submissions, quiz attempts, and completed recordings.
- Admin quiz manager supports multiple questions per quiz, single/multiple-choice options, correct answers, marks, explanations, edit/delete, and publish/unpublish.
